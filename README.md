# Pong Day 01

🎮 Primeiro projeto do desafio:
criar 1 jogo por dia para estudar desenvolvimento de games e TypeScript.

Já desenvolvo jogos utilizando Unity e Unreal Engine, mas queria aprofundar meus estudos em TypeScript e desenvolvimento web. Então decidi usar jogos como forma prática de aprendizado.

## Objetivos do projeto

- Estudar TypeScript na prática
- Melhorar lógica de gameplay
- Explorar mecânicas rapidamente
- Aprender desenvolvimento de jogos para web
- Publicar protótipos jogáveis online

## Tecnologias

- Phaser 3
- TypeScript
- Vite
- GitHub Pages

## Mecânicas estudadas

- Game Loop
- Input
- Colisão
- Física básica
- Movimento
- Sistema de pause
- IA simples da raquete inimiga

## Controles

W / S  
↑ / ↓  
ESC = Pause
ENTER = Restart
